\section{Implementation and evaluation details}
\label{sec:implementation}
All PushObj and Maze task lists reported in the main paper were used during method development. The training-recipe comparison covers both data collection and training settings; it is not a single-factor collection ablation. \Cref{sec:pending} discusses these points together with the planned source-disjoint holdout and matched collection factorial.
\subsection{Model and training objective}
The PushObj model uses a SmallResNetGeM visual encoder with 384 output dimensions and a six-layer action-conditioned transformer with 16 heads, feed-forward width 2048, and dropout 0.1. Proprioception and each block of five actions have learned ten-dimensional embeddings. A training window contains four observations spaced five control calls apart. Three context observations predict the corresponding one-step-shifted targets. Action embeddings condition prediction but are excluded from the prediction loss.

Let $z_i^o=[z_i^v;z_i^p]$ denote the concatenated observation representation of dimension $d_o=d_v+d_p$. Write $\hat z_{i+1}^o$ for the teacher-forced one-step prediction and $\operatorname{sg}$ for the stop-gradient operator. The offline objective is
\begin{align}
 \mathcal L_{\rm WM}&=\frac{1}{3d_o}\sum_{i=0}^{2}
 \norm{\hat z_{i+1}^o-\operatorname{sg}(z_{i+1}^o)}^2
 +\lambda_{\rm TS}\mathcal L_{\rm TS},\\
 \mathcal L_{\rm TS}&=\operatorname{mean}_{i\in\mathcal V}
 \left[1-\frac{\langle\Delta z_i^v,\Delta z_{i+1}^v\rangle}
 {\norm{\Delta z_i^v}\norm{\Delta z_{i+1}^v}}\right],
\end{align}
where $\Delta z_i^v=z_{i+1}^v-z_i^v$ and $\lambda_{\rm TS}$ is the inherited straightening coefficient. The mean averages valid adjacent displacement pairs across the training batch. The valid set $\mathcal V$ includes adjacent displacement pairs whose norms both exceed $10^{-6}$; the cosine calculation uses the same numerical floor. The TS term is zero if there is no valid pair. It acts on observed visual embeddings, whereas the prediction term averages all visual and proprioceptive coordinates jointly. This differs from the branch-normalized planning distance in \cref{eq:metric}. The target branch is stopped by gradient detachment; it is not an exponential-moving-average encoder.

The augmented-data PushObj models use $\lambda_{\rm TS}=0.01$, three epochs, effective batch size 64, and bf16 arithmetic. The encoder uses Adam at $10^{-5}$; the predictor and action/proprioceptive encoders use AdamW at $5\times10^{-4}$ with weight decay 0.01. Both optimizers use $(0.9,0.999)$ momentum coefficients. There is no offline learning-rate scheduler. The dataset contains 1,630,266 training windows and 403,951 validation windows. The seed-zero model additionally trains a detached decoder in epoch three, which has no role in planning; seeds one and two omit it.

Maze uses the released SmallResNet visual encoder without GeM, the same transformer dimensions, and a configured TS coefficient of 0.001. We reuse this model without new offline Maze training. Both released checkpoints used in the manuscript store epoch three; their configuration files specify a planned five-epoch schedule.

\subsection{Collection details}
The contact-biased dataset contains 4,000 training and 1,000 validation trajectories for each of T, L, Z, and $+$. Collection follows source placement, with up to four retries, 20-pixel positional jitter, and 0.3-radian angular jitter. The actual run configuration uses 9-pixel contact bias and Gaussian action noise with 10-pixel standard deviation per axis. Actions are stored in executed pixel units and divided by 100 for the environment API. Quality filtering checks scene validity and object displacements; the maximum accepted block displacement is below 80 pixels. Every retained trajectory has contact. Training and local validation source pools are separated, while the ancestry of the released evaluation sources relative to the original authors' training pool has not been established.

\subsection{Planning and model updates}
MPC optimizes 25 control actions and executes five. With frameskip five, this corresponds to a five-step latent rollout and one executed latent step. Action optimization runs 100 Adam iterations at initial learning rate 0.1, cosine-annealed to zero, without added optimization noise. The first plan starts from zero physical actions before normalization. Later plans warm-start from the unexecuted suffix and append zeros.

Maze uses an all-frame objective with weights proportional to $2^h$, including the context frame. PushObj uses a terminal-frame objective for its first five replans and the same all-frame objective subsequently. The all-frame implementation divides the normalized weighted sum by the number of frames. The memory term preserves this scale through its $1/(H+1)$ factor.

AdaJEPA performs one gradient update after each replan using the five latest execution segments. Its teacher-forced one-step prediction objective uses stopped targets and no online TS term. The final transformer block, final transformer normalization, and encoder projection are trainable; action and proprioceptive encoders remain fixed. Predictor and encoder learning rates are $5\times10^{-4}$ and $10^{-5}$. Adam is instantiated afresh for each update, so moments do not persist across replans. Predictor dropout is active for updates and disabled for planning. Model parameters and mutable buffers reset to the pretrained snapshot before each task. The correction gate compares prediction losses on successive executed transitions; it schedules intervention rather than testing model convergence.

\subsection{Exact success predicates}
For PushObj, with pusher and object positions $p_a,p_o\in\R^2$ and object angle $\phi$, success requires both
\begin{align}
 \norm{[p_a-p_a^g;\,p_o-p_o^g]}&<20\text{ pixels},\\
 |\operatorname{wrap}_{[-\pi,\pi)}(\phi-\phi_g)|&<\pi/9.
\end{align}
The position condition is a joint four-dimensional norm. Velocity is not part of this criterion. Maze success is the strict predicate $\norm{p-p_g}<0.5$, independent of velocity. We count success at replan boundaries; once successful, the task terminates and remains counted as successful for all larger reported budgets.

\paragraph{Exact goal objective.}
Write $\hat z_{t,0}=z_t$ for the initial context. The inherited objective is
\begin{align}
 J_{\rm last}(A;\alpha)&=D_\alpha(\hat z_{t,H}(A),z_g),\nonumber\\
 J_{\rm all}(A;\alpha)&=\frac{1}{H+1}
 \sum_{h=0}^{H}\omega_hD_\alpha(\hat z_{t,h}(A),z_g),\nonumber\\
 \omega_h&=\frac{2^h}{\sum_{k=0}^{H}2^k}.
 \label{eq:baseexact}
\end{align}
Here $J_{\rm goal}=J_{\rm all}$ throughout Maze, while PushObj uses $J_{\rm last}$ for the first five plans and $J_{\rm all}$ thereafter. Both $\omega_h$ and the regularizer weights $\pi_h$ are normalized, but $\omega_h$ includes the fixed context and $\pi_h$ weights only predicted states. The extra $1/(H+1)$ factor is inherited from the implementation; the memory amplitude uses the same scale. Main PushObj regularization begins after the terminal-only phase.

\paragraph{Update and activation order.}
After execution, the newest-transition error is measured, the optional online model update is applied, and motion is evaluated using the resulting encoder. Each positive trigger appends an observation and its weight, even while the gate is closed. For the trigger-only variant, the memory and three-call boost become available at the next plan. For the gated variant, the first feedback satisfying both $w_t>0$ and $q_t<\tau_g$ opens the gate permanently. Earlier memories then become active, and that feedback starts the boost. The gate requires one qualifying feedback, rather than several consecutive detections. A later positive trigger renews the boost interval; memory entries remain active after the boost expires. No memory deduplication, decay, or averaging by memory size is applied. Observation and model state reset between episodes. Detection starts after ten completed replans on PushObj and four in the Maze gating study. The main correction variants continue adapting after activation; model freezing is confined to the explicitly labeled controls.

\subsection{Paired evaluation and statistics}
\label{sec:paired}
Every Native/ECP comparison is paired at the task level. The PushObj component-ablation logs ($\gamma_{\rm hi}=0.15$) allow 40 replans and are truncated at 30; the threshold-ablation runs directly cap planning at 30. ECP cannot alter an episode in which no stall is detected, so episode selection reruns every task that triggers in the native trace and reuses all other trajectories, whether successful or unsuccessful. Permanent-weight controls change the first plan and therefore rerun all 350 tasks. Maze reruns the 51 adaptive and 50 frozen tasks with a potential trigger. Episode RNG, model reset, and within-shard indices are preserved, and actions and states are verified to match the native run before activation.

For paired outcomes, a rescue is unsuccessful under the baseline and successful under the intervention; a harm is the reverse. Given $u$ rescues and $v$ harms, the unadjusted two-sided exact sign/McNemar probability is
\begin{equation}
 p=\min\!\left(1,\,2\sum_{k=0}^{\min(u,v)}
 {u+v\choose k}2^{-(u+v)}\right).
\end{equation}
The main text reports task counts and effect sizes; reported $p$ values are unadjusted summaries on the development task lists.

\section{Properties of the stagnation regularizer}
\label{sec:properties}
For the full-latent construction, write $D_{\alpha_0}(z,m)=(z-m)^\top Q(z-m)$, where
\begin{equation}
 Q=\operatorname{diag}\!\left(d_v^{-1}I_{d_v},\,
 \alpha_0d_p^{-1}I_{d_p}\right).
\end{equation}
The matrix $I_d$ is the $d$-dimensional identity. For memory $m$ define $d_g=D_{\alpha_0}(m,z_g)>0$. When $\beta d_g\geq\epsilon$, the kernel denominator is $\rho=\beta d_g$, and
\begin{equation}
 K(z_g)=[1-1/\beta]_+^2=0\qquad(0<\beta<1).
\end{equation}
Its support radius is $\sqrt\beta$ times the memory-to-goal distance in the norm induced by $Q$. Inside the support $D_{\alpha_0}(z,m)<\rho$,
\begin{equation}
 \nabla_zK(z)=-\frac{4}{\rho}
 \left(1-\frac{D_{\alpha_0}(z,m)}{\rho}\right)Q(z-m).
 \label{eq:kernelgradient}
\end{equation}
Gradient descent therefore moves a predicted state away from a nearby memory. Both the kernel and its gradient vanish at the support boundary and beyond. At the exact memory center, the kernel is maximal but its gradient is zero.

The planner differentiates through the predicted rollout. If $G_{t,h}=\partial\hat z_{t,h}/\partial A$ is its action-to-latent Jacobian, then
\begin{equation}
 \nabla_A\mathcal R_t^{\rm stall}=
 \sum_{h=1}^{H}\pi_h G_{t,h}^{\top}
 \sum_{j\in\mathcal M_t}w_js_j\nabla_zK_j(\hat z_{t,h}).
\end{equation}
The regularizer acts on every future predicted frame and does not reward speed or require a straight physical path. The induced action gradient is determined by the learned Jacobians and favors predicted trajectories that leave the stored neighborhoods.

The $\epsilon=10^{-12}$ floor keeps degenerate denominators finite. When it is active, exact goal exclusion need not hold, while the full-latent memory amplitude $s_j$ also vanishes with its goal distance. An explored proprioceptive-space variant replaces only the kernel distance and radius with $\norm{z^p-m^p}^2/d_p$ and $\max\{\beta\norm{m^p-z_g^p}^2/d_p,\epsilon\}$; it retains the full-latent amplitude. All main $S$ results use the full-latent version. Repeated triggers add separate entries, so repeated stalls can increase the total local penalty.

\section{Backbone transfer}
\label{sec:backbone}
\subsection{Frozen LeWM with a contact objective}
A matched random-data LeWM replays the same source episodes without added contact bias or noise, using the same architecture, 16k/4k trajectories, and ten-epoch budget. On the same 350 tasks, native/ECP success is 166/186 (47.4/53.1\%), with 21 rescues and one regression. All 700 outcomes were verified by physics replay. Augmentation plus ECP reaches 66.0\%, an 18.6-point total gain (\cref{fig:headline}).

The LeWM study uses the augmented-data epoch-10 checkpoint, 350 H7t3 tasks (50 per shape, sampling seed 2000), and a frozen model. GD performs 100 iterations over a 25-control horizon, executes five controls per replan, and allows 30 replans. The trigger interval is 0.15/0.45 after a 50-control warm-up. Guidance persists for four replans per burst, with at most seven guided replans per task.

The contact extension uses observed simulator object pose and known shape geometry to select an approach waypoint, a pushing target, or the final pusher goal. These geometric inputs are shared across the matched contact-guidance controls. The added objective is
\[
 J_{\rm contact}(A)=10\operatorname{mean}_{k=1,\ldots,5;\,d=x,y}
 \left(\frac{\hat p_{k,d}(A)-q_d}{\sigma_{p,d}}\right)^2,
\]
where $q$ is the selected waypoint and $\hat p_k(A)$ is the pusher position predicted by differentiable PD dynamics from its observed position and velocity. The normalization uses dataset pusher-position standard deviations. This term acts jointly with the visual goal, stagnation regularizer, and conditional pusher-goal term during action optimization. The optimizer output is executed directly. This LeWM implementation uses an analytic pusher-position cost alongside its visual model. The headline figure and \cref{tab:lewm-contact} identify this geometry-assisted extension.

\subsection{Behavior after a trigger}
\label{sec:behavior}
We compare each triggered episode of the frozen augmented-data model ($\gamma_{\rm hi}=0.15$) with its native counterpart from the trigger onward. With ECP, the pusher moves more than 15 pixels away from the stalled position within three replans in 38\% of triggered episodes, versus 11\% under native planning. Within ten replans, the object error decreases by more than 5 pixels or the task succeeds in 34\% of triggered episodes, versus 1\% natively. ECP thus changes behavior promptly after the trigger, in line with the recoveries in \cref{fig:teaser,fig:execution-recovery}.

Let $p_t,p_g\in\R^2$ be observed current and goal pusher positions in pixels. With $v_t=p_g-p_t$, the executed-prefix offset is
\begin{equation}
 \delta a_t=\operatorname{unit}(v_t)
 \min\!\left(a_{\max},\frac{\norm{v_t}}{n_{\rm exec}}\right),
 \label{eq:kick}
\end{equation}

\section{Limitations and future work}
\label{sec:pending}
\paragraph{Evaluation scope.}
The PushObj and Maze task lists were used during method development, and the trigger threshold and LeWM contact weight were selected on them. The reported paired gains are therefore development results. Component interventions use one checkpoint per training recipe and were run at $\gamma_{\rm hi}=0.15$; the single-component variants were not re-evaluated at $0.45$. The paired statistics are unadjusted. The Maze gains correspond to two (frozen) and three (adaptive) additional tasks out of 100, and with AdaJEPA the PushObj gains concentrate on seen shapes (\cref{tab:threshold-shape}).

\paragraph{Representation-level stall detection.}
Stagnation is detected in the learned representation, so a visual shift that obscures the object state can also degrade the progress signal. On PushT, red-object success remains at 12\% for the frozen augmented model and reaches 18\% with AdaJEPA (\cref{tab:pusht-ecp}).

\paragraph{Search and backbone controls.}
The lookahead controls in \cref{tab:timing} share the execution budget of ECP but not its per-replan computation; a compute-matched comparison would quantify the relative cost of recovery by search and by objective correction. On LeWM, the gain comes from the geometry-assisted contact objective, which uses the simulator object pose and known shape geometry; the stagnation regularizer and pusher weighting alone add one and two tasks (\cref{tab:lewm-contact}), and the extension is evaluated on PushObj only. On DINO-WM with CEM, augmentation gives a large gain but ECP leaves outcomes unchanged at the tested settings (\cref{sec:dinowm}).

\paragraph{Planned evaluations.}
Planned studies, with hyperparameters and selection rules fixed beforehand, include: (i) a source-disjoint PushObj holdout and new Maze layouts and seeds; (ii) a matched collection factorial that varies directional bias and action noise separately under fixed source episodes, sample count, training schedule, and filters; (iii) the same $S$, $P$, and $S{+}P$ settings applied to three trained checkpoints, with paired success and across-seed uncertainty; (iv) a shared component matrix over trigger, loss gate, memory, temporary weight, and fixed-weight controls in both domains; and (v) a matched-budget analysis of object transport, residual agent positioning, and navigation recovery. Future work includes verified-recovery data aggregation and ACT-inspired temporally extended recovery.
