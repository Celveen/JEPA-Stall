\section{Conclusion}
Execution history can guide a world-model controller beyond repeated local behavior. ECP turns observed stagnation into a local trajectory regularizer and a temporary change in goal-component weighting, improving action selection with both frozen and adaptive dynamics. Interaction-rich data supply a complementary training-stage gain. Together, data augmentation and ECP raise PushObj success from 43.7\% to 72.3\% for frozen planning and from 69.4\% to 76.9\% with AdaJEPA under the same protocol. Component ablations and Maze recoveries show how correction timing and spatial memory contribute to this behavior. By using past execution to reshape future action selection, ECP makes planning responsive to the progress the controller actually achieves.
