\begin{abstract}
Latent world models plan from image goals, yet their objective is memoryless: it measures predicted goal distance without recording what the controller has already tried. When model mismatch, non-convex latent geometry, or branch-scale asymmetries prevent progress, replanning from nearly the same state can repeat failed actions, creating a closed-loop \emph{stall}. We propose \emph{Execution-Conditioned Planning} (ECP), a framework that turns an episode's own execution history into a corrective planning signal. ECP detects stagnation from the ratio of realized latent displacement to remaining goal distance, stores stalled observations in an episode-local memory whose goal-scaled potentials discourage revisiting traps (\emph{where} execution failed), and temporarily reweights the unfinished proprioceptive subspace (\emph{what} remains incomplete). Inspired by DART and ACT, we pair noisy, interaction-biased training data with sustained planning corrections at inference. ECP adds no learned parameters, acts entirely through the existing action optimizer, and applies to both frozen and online-adapted world models. On PushObj, success rises from 43.7\% to 72.3\% (+28.6~pp) with a frozen ResNet world model---surpassing online-adapting AdaJEPA (69.4\%) without test-time weight updates---and reaches 77.7\% with AdaJEPA. On PushT, we achieve 86.0\% clean and 63.7\% mean success across six visual shifts. ECP improves Maze navigation without regressions and reduces Rope Chamfer distance by 30.2\% with DINO-WM across three seeds. Code will be provided in the supplementary material.
\end{abstract}
